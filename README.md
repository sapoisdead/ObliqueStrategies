# Oblique Tarot - Brian Eno Strategy App

A mobile-first Progressive Web App (PWA) inspired by Brian Eno and Peter Schmidt's *Oblique Strategies*, designed with a vintage 19th-century tarot card aesthetic.

## 🚀 Quick Setup & Local Run

1. Clone or extract this project folder.
2. Open terminal and run:
   ```bash
   npm install
   npm run dev
   ```
3. Open `http://localhost:5173` in your browser.

## 📱 How to Deploy to Vercel and Install on Android

1. Push this code to a **GitHub repository**.
2. Import the repository into **Vercel** (or Netlify).
3. Copy your live URL (e.g. `https://oblique-tarot.vercel.app`).
4. Paste the URL into **[pwabuilder.com](https://www.pwabuilder.com)** to get a free Android `.apk` file!
